# 计时语音

用户于 2026-10-09 提供的 MiniMax 生成语音，供助手离线播放。运行时不连接 MiniMax，不需要 API Key。

| 文件 | 台词 | 时长 |
| --- | --- | --- |
| `circle_start.wav` | 三十秒后开始缩圈。 | 1.215 秒 |
| `circle_end.wav` | 三十秒后缩圈结束。 | 1.462 秒 |
| `rain.wav` | 雨中冒险剩十秒。 | 1.226 秒 |
| `art.wav` | 绝招剩三秒。 | 0.966 秒 |

格式为单声道、24 kHz、16 位 PCM WAV，总计 233,948 字节。由用户的同名台词 MP3 转换；原始文件保持不变。仅裁剪多余的首尾静音，保留约 60 毫秒起始余量、120 毫秒结束余量及句内停顿，不调整音色或语速。四条语音统一到约 -18 dBFS RMS，峰值低于 -3 dBFS，文件边缘有 5 毫秒淡入淡出。

WAV 随源码保存，并通过 PyInstaller spec 内嵌到 `assets/sounds`。不依赖工作目录或用户桌面上的 MP3。音量按现有设置缩放；文件缺失或损坏时，该类提醒回退到原有短提示音。

开始和结束缩圈语音在第一圈、第二圈及不同天数间复用。自动播报期间不插播或排队补播其他节点；手动试听可以切换语音。切出游戏、关闭提醒或退出助手仍停止自动播放。
