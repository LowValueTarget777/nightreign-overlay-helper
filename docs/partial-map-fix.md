# 地图信息丢失模式修复

2026-09-06：运行日志中，该模式多次只确认 1 个地标，未达到生成候选所需的 2 个；关闭该模式后，普通识别能够生成候选。

发现的确定性问题是普通建筑与 DLC 建筑共用图标时，被视为两个竞争类别。四组相同图标（34/525、38/524、40/511、41/510）分数相同，无法通过第一名与第二名的差值要求。15 个类别中有 8 个因此连标准图标合成输入都无法确认。

修复按完全相同的 RGBA 图像合并视觉类别，候选布局比较也使用同一映射。因此相同外观仍可对应多个布局，不会强行区分普通/DLC 建筑。另增加同一匹配位置的图案相关性校验（至少 0.65），排除仅亮度接近的地形误报。保留原有误差阈值、不同外观间的分差要求及连续两次观察确认机制。

回归覆盖所有 15 个建筑类别、普通/DLC 候选兼容、两地标生成候选、空白画面，以及两张去除建筑的地形背景。测试命令：

```powershell
.\.venv\Scripts\python.exe -m unittest scripts.test_partial_icon_aliases
```

这是针对确定性缺陷的修复。该模式仍是实验功能，使用固定地图坐标并允许小幅位置偏移；不同分辨率、缩放、遮挡和地图丢失事件下的实际识别率仍需游戏内验证。标准图标合成测试不能代替实机验证。
