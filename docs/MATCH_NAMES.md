# 队友名字与留言点赞

当前试用版本 `0.10.10.dev11`，位于 `LVT/status-sound-alerts`；fork 的 `main` 保持 `0.10.10.dev9`。原开发历史保留在 `LVT/match-name-block`（`091bc22`），从 `bcb79c4` 建立。保留统一延迟框、独立限时点赞窗口和可选累计匹配次数，修复短暂名单/心跳波动误解除及 Steam 游戏状态占用，未使用游戏内存、OCR 或头像左侧 HUD。旧版本验收记录见 PROJECT_STATUS.md。

## 使用

退出旧助手，运行 `dist/nightreign-status-sound-alerts/nightreign-overlay-helper.exe`。升级时旧组件先恢复并退出，通常空闲一分钟后自动交接；新版检查 `match_hold_v4`，不会复用旧版持有逻辑或覆盖仍在恢复的旧组件状态。设置 → 队友信息可开启“读到队友延迟后自动屏蔽通信以显示 Steam 名字”，首次默认关闭、保存后记忆。

开启后，活动名单新鲜、连接正常、非好友且具有有效非负整数 Ping 即可尝试，不再依赖 DAY1、前台状态或入队时间窗口。在大厅也可以开始处理，游戏里名字切换仍依赖游戏自身进入对局后的行为。

Steam 好友、已屏蔽、未知关系和好友申请中的玩家跳过。当前接口没有邀请/匹配来源，未加好友的受邀玩家也可能符合条件。每轮最多三次只读准备，间隔 2 秒、4 秒，页面最多等待 45 秒并轮询就绪状态。网页准备超时/菜单未就绪/Steam 提交前连接失败后，按 30、60、120、180 秒退避继续尝试，后续封顶三分钟，离队或关闭功能停止新尝试。提交前取消仅在重新满足当前条件时重试；账号不符、原有屏蔽、磁盘落盘失败不重复尝试。已经发出屏蔽或结果不确定时先恢复，不重发 POST。

Steam 可把数字资料地址跳到自定义 `/id/` 地址；两种都支持，但同时检查页面目标 SteamID、原账号及新导航令牌，不能只按网址形状操作。

连续新鲜活动名单确认离队十秒后请求解除；短暂空名单、connecting 和缺失 Ping 不立即解除，快照断档重新计时。已屏蔽目标遇到组件报错或名单停更最多宽限三十秒，之后请求恢复。真实游戏退出、功能关闭、退出助手或账号失效仍请求解除；helper 启动/重启的“等待游戏”不等于游戏已退出。活动名单并非游戏房间回调，旧 P2P 会话清理可能延迟；同一人返回时先完成旧恢复再重新判断。

## 通信状态标记

延迟窗口在对应姓名下显示准备屏蔽、已屏蔽、解除中、已解除、失败待重试或恢复待确认等状态；点赞窗口也可看到同一目标的通信状态。以原有执行组件报告为准：提交请求不等于已屏蔽，组件空闲不等于已解除；只有收到解除确认才显示成功。好友跳过、原有屏蔽另行标记，原有屏蔽不由助手自动解除。

队友离开活动名单后，恢复状态继续显示在联机框底部“近期队友”，没有旧 Ping；完成结果最多四项、保留两分钟，待恢复不因两分钟到期消失。真实游戏退出立即隐藏旧 Ping，仍可显示通信恢复；“仅在游戏时显示”以及队友信息总开关仍控制窗口可见性。助手重启可接续旧恢复状态，尚未取得名字时显示 SteamID。

## 结束后点赞

“显示对局后队友留言点赞入口”默认开启；留言可自定义，长度 1–500 字。点击上局队友名字，在 Steam 内置浏览器打开该队友主页；只有点击名字右侧的“点赞”按钮才发送自定义留言。七天冷却或发送期间仅禁用点赞按钮，名字仍可点击。名单出现、启动助手及重复匹配都不会自动留言。

实际前台 DAY1 记录本局最多两位 Steam 队友。每人分别连续三秒不在新鲜活动名单中时，**只显示离开者** 的独立点赞窗口；受邀好友留房不挡住野人的入口。每人显示两分钟后收起，其他人后来离开不延长旧条目的时间；可以拖动或点 × 提前关闭，位置单独保存。下一次 DAY1 立即收起，重启不显示旧入口；短暂名单缺席、重连或组件报错不触发。没有精确结算事件，中途掉线也会按离队弹出；打完全部留在房间、识别错过 DAY1 或中途启动，可从右键菜单选择“结束本局 / 显示队友点赞入口”。名单及七天间隔仍保留。

发送时才连接 Steam 网页组件，使用主页自身的评论线程，检查当前账号、目标和是否开放留言；暂时屏蔽未解除时不留言。消息直接作为普通文本提交，不保存浏览器 Cookie 或会话。

每个 Steam 账号对同一目标默认七天间隔。记录位于 `%LOCALAPPDATA%/NightreignOverlayHelper/identity/commendations`，发送前原子落盘并加目标锁。成功、网络结果不确定或发送过程崩溃，都保留间隔，防止重复留言；结果不确定请到主页核对。服务器明确拒绝或网页在提交前明确拒绝时，一分钟后允许手动重试，不会自动重发。记录损坏或无法落盘时停止发送。

## 累计匹配次数

设置 → 队友信息 →“记录非好友队友的累计匹配次数”，默认关闭、切换立即记忆。按用户选择只记录非好友，与屏蔽和点赞开关独立，仍需启用队友信息。开启后显示每位已记录队友的“累计匹配 N 次”，位于延迟框的名字下方及独立点赞窗口；没有历史的玩家不显示次数。

以实际前台 DAY1 为开局确认，首分钟接收本局最多两位队友的新鲜名单，等待 Steam 好友关系确认。同一 SteamID 每局只计一次，名单刷新、改名、掉线重连、关闭再打开不重复计数，下一局再遇到加一。普通非好友（关系 0）和已屏蔽通信的非好友（关系 5）可记录，好友（3/6）、未知与申请中关系跳过。首分钟之后不把新的大厅连接补记到上一局。助手中途启动或开启时没有看到 DAY1，就从下一次确认开局开始，不补历史次数。

记录只在本地 `%APPDATA%/nightreign-overlay-helper/encounters/{当前 Steam 账号}.json`，包含 SteamID、最近记录时的昵称、累计次数和本局去重信息。次数与去重状态一次原子保存，账号文件锁防止两个助手同时重复计数；短暂 DAY1 重启重见结合开机时钟和 UTC 去重。断网不会删除历史；保存失败不提前显示增加的数字，已观察到的队友在后续名单更新时重试保存。记录损坏则保留文件并暂停写入。关闭功能不清空历史，Steam 账号切换分别保存。接口没有邀请/匹配来源，未加好友的邀请玩家也会按非好友记录。

## 独立通信恢复

两位屏蔽目标各使用独立通信监督进程，记录在 `%LOCALAPPDATA%/NightreignOverlayHelper/identity/match-0` 与 `match-1`。监督进程不连接 Steam；每次由短期子进程负责屏蔽、持有与一次恢复，任务结束时释放网页、关闭 Steam API 并真正退出，避免已关闭游戏仍因空闲通信组件显示“正在游戏”。实际任务使用黑夜君临 AppID，未完成恢复期间的重试仍可能暂时显示在游戏。

屏蔽前保存原账号、目标、事务与关系；主应用每秒续约，短暂状态读取/写入失败对已验证目标保留三十秒，期间不允许新屏蔽。原生续约期限三十秒、网页独立看门狗九十秒，仍检查账号、游戏、撤销和四小时上限；屏蔽后不以临时 P2P 断连解除。正常退出请求恢复，不强杀恢复进程。

解除必须核对新网页和 Steam 关系，并持久化完成记录。网络失败、Steam 退出、账号切换、磁盘异常时保留恢复记录；每次有限恢复任务失败后退出，由监督进程等待十五秒再试，主程序崩溃后仍可继续。启动助手优先检查旧恢复，即使开关关闭也不忽略；损坏记录保留并暂停自动操作。不要删除恢复记录；整机断电、监督进程被强杀或 Steam 无法登录时，重新运行新版助手并保持原账号在线继续恢复。无法联网或登录原账号时不能保证即时解除。
